Semantic diversity over time

Earlier generations are faded; the displayed generation is opaque. Larger points represent identical prompts from multiple strategies.

Colors identify exploratory HDBSCAN groups in the original embedding space. The fixed map is fit across all completed generations for this case. Coordinates and colors belong to this case alone.

2D geometry is approximate. The line chart uses original embedding distances, equally weighted across cases. Lower nearest-neighbor distance indicates closer local variants; it does not establish that every group contracts.

Each case has its own shared map to prevent topic differences from inflating strategy diversity. No model calls or external assets are used by this page.
